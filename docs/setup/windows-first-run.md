# Lowk на Windows: первый запуск

Для компьютера с Windows 11. Ничего ставить от администратора не нужно.

## 1. Скачать установщик

1. Откройте в браузере страницу проекта на GitHub и вкладку **Actions**.
2. Слева выберите **release-build**.
3. Нажмите на самую верхнюю запись с зелёной галочкой (последняя удачная сборка).
4. Прокрутите страницу вниз до блока **Artifacts**.
5. Нажмите **lowk-windows-x64-vulkan**. Скачается zip-архив.
6. Правой кнопкой по архиву, **Извлечь всё**, **Извлечь**. Внутри будет файл `Lowk_..._x64-setup.exe`.

Если зелёной записи нет, попросите нас запустить сборку: Actions, release-build, **Run workflow**, `windows_gpu = vulkan`, `platforms = windows`. Ждать примерно 30 минут.

## 2. Установить

1. Дважды нажмите на `Lowk_..._x64-setup.exe`.
2. Windows покажет синее окно **«Windows защитила ваш компьютер»**. Это нормально: у программы пока нет платной подписи. Нажмите **Подробнее**, затем **Выполнить в любом случае**.
3. Выберите язык, нажмите **Далее**, **Установить**. Папку не меняйте.
4. Если Windows предложит скачать WebView2, разрешите (это маленький компонент от Microsoft). Нужен интернет.
5. Нажмите **Готово**. Lowk откроется сам. Позже его можно найти в меню «Пуск».

## 3. Первый запуск

Lowk проведёт по нескольким шагам:

1. **Язык** выберите «Русский».
2. **Источник звука**: выберите «Одно приложение» и в списке нажмите **Контур Толк** (Kontur Tolk). Если его нет, откройте Толк и нажмите в Lowk кнопку обновить; приложение появляется в списке, когда оно открыто. Если всё равно не видно, выберите «Вся система»: Lowk запишет всё, что играет на компьютере (кроме собственных звуков Lowk).
3. **Разрешения**: на Windows почти всё уже разрешено. Микрофон нужен только если вы хотите записывать свой голос.
4. **Железо**: Lowk покажет вашу видеокарту (RTX 3060) и предложит локальный движок.
5. **Движок**: см. следующий раздел.

## 4. Локальный движок или Deepgram

- **Локальный**: всё считается на вашем компьютере, звук никуда не уходит. При первом выборе Lowk скачает модель (около 600 МБ и ещё одну, поменьше, для поиска). Нужен интернет один раз. Видеокарта используется автоматически.
- **Deepgram (облако)**: быстрее стартует и не грузит компьютер, но звук уходит в Deepgram.

Как включить Deepgram:

1. Откройте у себя файл с ключом Deepgram (тот, что у вас уже есть) и скопируйте ключ целиком.
2. В Lowk: **Настройки**, раздел с провайдерами, строка **Распознавание**, выберите **Deepgram**.
3. Появится поле **Ключ Deepgram**. Вставьте ключ (Ctrl+V), нажмите **Сохранить**. Ключ хранится в «Диспетчере учётных данных» Windows, не в файлах Lowk. Windows ничего спрашивать не будет.
4. Нажмите **Проверить**: должно появиться «Ключ работает».

Для итоговой выжимки (саммари) нужен ещё один ключ, OpenRouter, в том же разделе, поле **API-ключ**. Вставляется так же.

## 5. Папка «без микрофона»

Чтобы Lowk не трогал микрофон при лекциях:

1. На главной нажмите **Новая папка**, назовите её «Лекции».
2. Откройте папку, найдите настройку **Микрофон в этой папке** и выберите **Выключен**.

Запись в этой папке не открывает микрофон вообще: значка микрофона в трее не будет. Во время записи микрофон можно включить кнопкой в оверлее.

## 6. Пробная запись на 5 минут

1. Откройте Контур Толк и включите любое видео или подключитесь к тестовой встрече, чтобы шёл звук.
2. В Lowk нажмите **Начать запись**, выберите папку «Лекции» и источник «Контур Толк».
3. Через 5–10 секунд в оверлее появится текст. Проверьте, что русские слова и английские термины распознаются.
4. Через 5 минут нажмите **Стоп**.
5. Откройте запись в папке «Лекции» и нажмите **Саммари**. Выжимка появится через минуту.
6. Если закрыть и снова открыть Толк во время записи, Lowk подключится к нему заново (до двух секунд тишины в записи).

Что проверить и сообщить нам: шёл ли текст без больших задержек, слышен ли был звук из Толка вам самим (должен), записалась ли выжимка.

## 7. Если что-то не работает: логи

1. В Lowk: **Настройки**, **Хранение**, строка **Журнал работы**, кнопка **Открыть папку логов**.
2. Откроется папка `C:\Users\<ваше имя>\AppData\Roaming\Lowk`. В ней файл **lowk.log** (и, если есть, **lowk.prev.log**).
3. Отправьте нам эти файлы. Ключи в журнал не попадают.

Если Lowk не запускается совсем, откройте эту папку вручную: нажмите Win+R, вставьте `%APPDATA%\Lowk`, Enter.

В журнале есть строка «STT worker runs on the GPU backend» (хорошо, работает видеокарта) или «runs on the CPU» (видеокарта не использована; напишите нам или переключитесь на Deepgram).

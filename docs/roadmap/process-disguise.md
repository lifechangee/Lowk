# Маскировка процесса: имя, иконка, «копирование чужого внешнего вида»

Статус: дизайн, 2026-10-22. База: `docs/research/stealth.md` §5 (технические детали там; здесь - решение и план). BRIEF §5: процесс не прячем (руткит-техники отклонены), только переименование и смена иконки, в т.ч. внешний вид другого приложения.

## 1. Что именно видит пользователь/зритель

| Поверхность | macOS | Windows |
|---|---|---|
| Dock/панель задач, Cmd/Alt+Tab | иконка + имя bundle | иконка окна + заголовок |
| Меню-бар: имя приложения | `CFBundleName` | - |
| Monitor | Activity Monitor: имя исполняемого/bundle | Task Manager: `FileDescription`; вкладка Details: имя .exe |
| Принудительное завершение / автозапуск | Force Quit, Login Items: bundle | Автозагрузка в диспетчере: имя записи Run |
| Демонстрация экрана | оверлей и так исключён (stealth), главное окно - нет | то же |

Честные пределы: `ps`/Process Explorer, путь к файлу, подпись и хэш бинаря, командная строка раскрывают реальный бинарь; корпоративный EDR и MDM видят оригинал. Маскировка - косметика от случайного взгляда, не защита.

## 2. Три уровня (рекомендуемая модель)

1. **Уровень 1 - рантайм (по умолчанию доступен всем, безопасный).** Только то, что меняется без копирования файлов:
   - macOS: `NSApp.applicationIconImage`, заголовки окон, пункты главного меню; активация `LSUIElement`/`NSApplicationActivationPolicy` (оверлей и так без Dock-иконки).
   - Windows: `WM_SETICON`, `SetCurrentProcessExplicitAppUserModelID`, заголовки, tray tooltip.
   - Не меняет Activity Monitor/Task Manager, TCC и подпись не затрагиваются, антивирусы не реагируют.
2. **Уровень 2 - «теневая копия» с другим именем и иконкой (по запросу).** Изменяется отображаемое имя процесса.
   - **macOS:** копировать `Lowk.app` в `~/Library/Application Support/Lowk/Disguise/<Имя>.app`; переписать `Info.plist` (`CFBundleName`, `CFBundleDisplayName`, `CFBundleExecutable` + переименовать бинарь, `CFBundleIdentifier` с уникальным суффиксом, `CFBundleIconFile` + `.icns`); пересобрать подпись (`codesign --force --deep -s -`; на Apple Silicon ad-hoc обязателен, иначе не запустится; при наличии Developer ID - подписывать им, тогда TCC стабильнее); не ставить карантин; запустить через `open`, завершить исходный. Всё делает helper внутри приложения (`Security.framework`/`Process` вызов `codesign` из `/usr/bin`).
   - **Windows:** копировать `Lowk.exe` + ресурсы в `%LOCALAPPDATA%\<Папка>\<Имя>.exe`; по выбору записать иконку и `FileDescription`/`ProductName` в копию через `BeginUpdateResource`/`UpdateResource`; запустить, завершить исходный. Режим «без патча ресурсов» (меняется только имя файла) - с меньшим риском эвристик. WebView2: задать отдельный `WEBVIEW2_USER_DATA_FOLDER`, иначе в командной строке `msedgewebview2.exe` виден идентификатор Lowk.
3. **Уровень 3 - «скопировать внешний вид приложения X».** Считывание метаданных другого установленного приложения (имя, иконка) и применение на уровне 2.
   - macOS: прочитать `/Applications/X.app/Contents/Info.plist`; иконка - из `CFBundleIconFile` (.icns) или через `NSWorkspace.shared.icon(forFile:)` (для Assets.car) -> сохранить как .icns/PNG.
   - Windows: `ExtractIconEx`/`SHGetFileInfo` для иконки, `GetFileVersionInfo` для `FileDescription`/`ProductName`.
   - Всё локально, ничего не загружается и не передаётся.

Принцип дизайна: **косметика, локально, обратимо, не мешает защитным средствам.** Нельзя: подделка подписи/издателя, имитация системных процессов, изменение прав и защитных настроек, внедрение в чужие процессы, скрытие из списка процессов (руткит-подходы отклонены владельцем).

## 3. Guardrails для уровня 3 (это важная часть)
- Не предлагать для копирования: системные приложения (Finder, System Settings, Activity Monitor, Terminal, Task Manager, Explorer, cmd/PowerShell), приложения безопасности (антивирус, EDR, VPN-клиенты корпоративные, менеджеры паролей, MDM-агенты). Список блокировок хранится в приложении.
- Явное подтверждение с предпросмотром («Ваш процесс будет отображаться как "Slack" и иметь его иконку»), запись в локальный журнал.
- Не копировать издателя/подпись: в `Info.plist`/версионной информации не писать `CFBundleIdentifier`/`CompanyName` оригинала (идентификатор уникален; поле «компания» оставить пустым или «Lowk»).
- В диалоге предупреждение: это изменяет отображение, а не сущность; на рабочих устройствах с политиками безопасности такая подмена может нарушать правила (MITRE T1036.005 «Masquerading» - классическая эвристика EDR).
- Не распространять заранее замаскированные сборки; маскировка создаётся только на машине пользователя из его же копии.
- Возможность «вернуть как было» одной кнопкой (удаление теневой копии, возврат к оригинальной).

## 4. TCC и права (macOS)
- TCC (Screen Recording, Microphone, Accessibility, Input Monitoring, Camera) привязаны к bundle id + идентичности кода. Теневая копия = новое приложение для системы -> все разрешения запрашиваются заново; Screen Recording на Sequoia+ дополнительно переспрашивается периодически [известно, проверить на 27].
- Рекомендация: **выбор маскировки - часть онбординга до запроса разрешений**; повторная смена = повторные запросы (предупредить в UI и дать чек-лист).
- Улучшение: если появится Developer ID (см. virtual-camera.md), подписывать копию им и держать `CFBundleIdentifier` стабильным (например `com.lowk.app` + суффикс не менять при смене имени): TCC привязывается к designated requirement, а не к имени -> разрешения могут сохраниться при смене только имени/иконки [проверить].
- Оригинальное приложение остаётся в системе; в TCC-списке будут две записи (Lowk и копия) - убирать старую вручную (`tccutil reset` недоступен для чужого bundle без явного id; инструкция пользователю).
- Windows: специальных разрешений нет (камера/микрофон - privacy settings по пути exe: смена пути = новая запись «камера разрешена» для классических приложений, но для Win32 это обычно по пути, пользователь может увидеть новый запрос).

## 5. Антивирусы и ложные срабатывания
- Паттерн «самокопирование в AppData + патч ресурсов + запуск + завершение исходного» похож на дроппер. Новый неподписанный хэш при каждой смене = низкая репутация (Defender cloud, SmartScreen не затрагивает локальные файлы без Mark-of-the-Web, но ML-эвристики могут).
- Смягчение: (1) уровень 1 по умолчанию; (2) режим без патча ресурсов; (3) подписанный Authenticode-бинарь (желательно) - репутация издателя; (4) документировать исключения Defender, не добавлять их программно (иначе правка защитных настроек - запрещено); (5) отправлять образцы в Microsoft/Google для ложных срабатываний; (6) на macOS - ad-hoc копия не вызывает Gatekeeper, но XProtect/MRT могут реагировать на изменённые bundle - низкий риск.
- Mac: копия из `~/Library/Application Support/...` не в `/Applications` -> App Translocation не применяется, т.к. нет карантина.

## 6. Рекомендованный безопасный дизайн
1. Настройка «Внешний вид приложения» в Настройках: «Lowk (по умолчанию)» / «Своё имя и иконка» / «Как у приложения...» (список установленных безопасных приложений).
2. Рантайм-часть применяется мгновенно; процессная часть (уровень 2) - после подтверждения и рестарта.
3. Логика в крейте `lowk-platform` (модуль `disguise`) + UI в Settings; никакого скрытого автоприменения.
4. Тесты: golden-тест `Info.plist` до/после; интеграционный `just qa-bundle` проверяет, что после маскировки копия запускается, стелс по-прежнему работает (оверлей скрыт от захвата), разрешения запросятся заново (ожидаемо); Windows - смоук копии в VM.
5. Журнал в `<app data>`, ничего в vault и в облако.

## 8. Риски
- EDR/MDM на корпоративных устройствах помечают подмену как masquerading -> риск для пользователя; предупреждение обязательно.
- Юридический/репутационный: имитация сторонних брендов (иконки, торговые марки); применять только к приложениям, установленным у самого пользователя и локально.
- Повторные запросы TCC на каждую смену - раздражает; ограничить частоту смены.
- Обновления Lowk (updater) должны пересоздавать теневую копию - иначе она останется на старой версии (миграция: при апдейте пересобрать копию автоматически).
- Две копии одного приложения (оригинал и копия) путают Launch Services и автозапуск.

## 9. Открытые вопросы владельцу
1. Достаточно ли уровня 1 (иконка/заголовки в Dock/панели) или принципиально нужно имя в Activity Monitor/Task Manager (уровень 2)?
2. Список «безопасных» приложений для копирования - ок как блок-лист (Finder, System Settings, антивирусы)? Что ещё исключить/разрешить (Zoom, Slack, Chrome...)?
3. Можно ли честно предупреждать о корпоративных политиках и не предлагать функцию на управляемых устройствах (определяется по MDM-профилю)?
4. Допустимо ли требовать перезапуск и повторную выдачу разрешений при смене маски (macOS)?
5. Нужна ли подпись Windows (OV/EV или Azure Trusted Signing) ради меньшего количества срабатываний?

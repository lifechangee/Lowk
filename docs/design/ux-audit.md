# UX-аудит главного окна Lowk (M1, мок-UI, 1360×840)

Повод: «главное окно разрозненное, нет общей логики». Скриншоты — `docs/design/ux-audit/`, сняты с `ui` (vite + мок IPC), RU. Предложение и кликабельный макет: `docs/design/ux-v4.html`.

## Что есть сейчас (карта экранов)

| Экран | Скрин | Каркас |
|---|---|---|
| Библиотека (home) | 01-home | без сайдбара, центральная колонка |
| Папка | 03-folder | 3 панели: дерево / список / «Папка» справа |
| Несортированные, Корзина | 04, 05 | 2 панели (справа пусто) |
| Страница созвона | 07, 08-call-tab1..3, 08-call-md | 3 панели + 4 вкладки + «Исходник .md» |
| Поиск ⌘K | 13-search(-query) | модалка поверх чего угодно |
| Новый созвон | 14-newcall-popover | поповер из шапки (на home — карточка) |
| Настройки (6 стр.) | 12-settings-* | свой сайдбар, дерево пропадает |
| Онбординг (8 шагов) | 02-onboarding-0..7 | полноэкранный, свой сайдбар шагов |

## Что не так

### 1. Три разных каркаса, навигация «прыгает»
- Home — без сайдбара; папка — с деревом; настройки — с другим сайдбаром; онбординг — с третьим. Положение «Назад/домой» меняется (01 vs 03 vs 12).
- Нет постоянного «где я»: левая колонка то дерево папок, то список настроек, то отсутствует.

### 2. Дубли входов в одно и то же
- Домой ведут 3 элемента: логотип «Lowk», крошка «Библиотека», кнопка «← Библиотека» в дереве (03).
- Настройки: шестерёнка в шапке и «Настройки» внизу дерева (03, 07) — два места, разные иконки.
- Поиск: поле в дереве, поле на home, ⌘K — три вида одного.
- «Новый созвон»: карточка на home, кнопка в шапке на остальных экранах, поповер (14) — разные формы одного действия; в открытом поповере кнопка в шапке теряет подпись (14, баг).
- Таблица «Структура» справа на странице созвона (07) дублирует вкладки центра.
- Саммари: кнопка «Саммари» в заголовке + вкладка «Саммари» (08-tab1).

### 3. Действия лежат где попало
- Переместить/удалить созвон: ⋯ в списке, drag-and-drop, «Перенести в папку» и «В корзину» в правой панели созвона, «Переместить в…». Для папки — действий нет вовсе (переименовать/удалить где?).
- Экспорт: «Исходник .md» + иконка скачивания в одной строке с вкладками (07) — вперемешку с навигацией.
- Документы папки и инструкции спрятаны в правой панели мелким блоком (03), хотя в M2 это основной контент папки.

### 4. Иерархия и именование
- Правая панель называется «Папка» / «Свойства созвона», при этом на вкладке «Созвон» заголовок «Папка …» (07): путаница, свойство чего показано.
- Две системные папки живут внизу списка отдельно от «Папки» и выглядят иначе (карточки-«пилюли» на home, строки в дереве).
- Теги — отдельный блок внизу дерева; клик по ним скрыто фильтрует, но результат нигде не показан.
- Термины: «Библиотека» (крошка/home) и «Хранилище» (настройки, бриф), «Созвон/Звонок», «Саммари/Сводка», «Вопросы к AI/нейронке» — не едины.
- Крошки дублируют дерево и заголовок страницы: «Библиотека / Acme Corp / Квартальное…» + H1 с тем же текстом + выделенная строка в дереве.

### 5. Пустые состояния и баланс
- Папка без документов/инструкций (06): пустой textarea и пунктирная зона без объяснения, зачем это; центральная колонка пуста и не зовёт «Начать созвон здесь».
- Несортированные/Корзина (04, 05): 70% экрана пустые, подсказка серым текстом, нет примера действия. Правая панель отсутствует — сетка меняется при переходе.
- Центральная колонка шириной 700 px то слева, то по центру (03 vs 04): контент «плавает».
- Главная («Доброе утро + 11 звонков») не отвечает на «что дальше»: нет «последних созвонов» и «продолжить», только папки.

### 6. Онбординг и первое использование
- 8 шагов настройки (02), после них — пустой home без объяснения, как пользоваться оверлеем и биндами. Бинды знает только тот, кто открыл «Горячие клавиши». «Первоначальная настройка» в настройках (12-general) перезапускает именно установку, а не обучение.

### 7. Мелочи
- Моно-иконка «настройки» (ползунки) выглядит как «фильтры».
- Разные радиусы/плотности: поиск в дереве, карточки home, строки списка.
- Нижний блок дерева («Теги», «+ Новая папка», «Настройки») смешивает навигацию, фильтры и действия.

## Корневая причина
Приложение выросло как набор экранов (home из варианта B, папка из A, настройки отдельно), а не как одна модель: нет единого ответа на «где я / что тут можно / как начать созвон».

## Принципы нового каркаса
1. Один постоянный левый сайдбар на всех экранах (кроме онбординга и оверлея).
2. Один «Новый созвон» — всегда один и тот же поповер (папка, источник, языки), одна кнопка в одном месте.
3. Контекст страницы = заголовок + крошки + вкладки; действия (⋯, экспорт, перенос, удалить) — в одном месте справа от заголовка.
4. Правая панель — только по необходимости (свойства, источники), не носитель контента.
5. Каждое пустое состояние: что это, зачем, одна кнопка.

См. 2 варианта IA, рекомендацию и тур первого запуска в `ux-v4.html` (ниже — текстовая фиксация).

# Информационная архитектура

## Общая часть (в обоих вариантах)
- Сайдбар: логотип · «Новый созвон» (primary) · Главная · Поиск ⌘K · Папки (дерево) · Несортированные · Корзина · внизу «Настройки» и индикатор записи.
- Настройки — тоже раздел сайдбара (внутри — свои вкладки сверху, не второй сайдбар).
- Папка = рабочее пространство с вкладками **Созвоны / Документы / Инструкции** (M2: закреплённые документы — звёздочка в «Документах»; теги — в шапке папки).
- Созвон: вкладки **Транскрипт / Саммари / Вопросы к AI / Скриншоты / Документы-источники**; «Исходник .md», экспорт, перенос, корзина — в меню ⋯ в шапке.
- Поиск ⌘K — палитра из любого места; «Поиск» в сайдбаре открывает полную страницу результатов с фильтрами папка/тег/дата (M2).
- Крошки в шапке контента: `Папки / Acme Corp / Созвоны`. Единственное место «домой» — «Главная» в сайдбаре.
- «Чат с AI по созвону» (M3+) — будущая вкладка созвона и кнопка в шапке папки, место зарезервировано.

## Вариант A — «Сайдбар + рабочее пространство» (рекомендуется)
Сайдбар со всем деревом папок; контент — полноширинный, правая панель только в созвоне (источники/свойства, сворачиваемая).
- Плюсы: привычная модель (Notion/Obsidian/Finder), масштабируется на сотни папок и документов, один каркас на всех экранах, прямое соответствие хранилищу на диске.
- Минусы: дерево занимает 240 px; при малом числе папок кажется пустым; «Главная» остаётся отдельным экраном.

## Вариант B — «Верхние разделы + карточки»
Верхняя навигация: Главная · Папки · Поиск · Корзина · Настройки; «Папки» — сетка карточек, внутри папки хлебные крошки и вкладки; нет постоянного дерева.
- Плюсы: больше места контенту, просто для новичка, меньше «админки» на экране.
- Минусы: смена папки = 2 клика через сетку; плохо при частом переключении между созвонами разных проектов; drag-and-drop созвонов между папками неудобен; хуже масштабируется на M2–M3.

## Рекомендация
A. Владелец ежедневно ведёт много созвонов в нескольких папках (бриф: «созвоны ежедневно, по несколько в день») — нужно мгновенное переключение и drag-and-drop, а дерево уже есть в коде (FolderTree). Это эволюция существующего, а не переписывание: объединить три каркаса в один, убрать дубли, перенести правую панель папки в вкладки «Документы/Инструкции».

## Где какое действие (контракт размещения)
| Действие | Место |
|---|---|
| Новый созвон | кнопка сверху сайдбара (+ ⇧⌘R); поповер: папка, источник, языки |
| Новая папка | «+» в заголовке секции «Папки» |
| Поиск | «Поиск ⌘K» в сайдбаре |
| Переместить/удалить/экспорт | ⋯ справа в шапке страницы + контекстное меню строки |
| Добавить документ | вкладка «Документы» (кнопка + drag-and-drop) |
| Настройки | низ сайдбара (один вход; шестерёнку из шапки убрать) |
| Тур | «Настройки → Общие → Показать тур» и «?» в сайдбаре |

## Пустые состояния (текст)
- Главная без созвонов: «Здесь появятся ваши созвоны. Нажмите «Новый созвон» — оверлей покажет субтитры и подскажет ответы по ⌘↵.»
- Папка без созвонов: «В этой папке пока нет созвонов» + кнопка «Новый созвон здесь».
- Документы: «Перетащите сюда PDF, DOCX, TXT/MD, таблицы, слайды. Lowk будет подсказывать из них во время созвона.»
- Инструкции: пример («Клиент — финтех, общаемся на «вы»…») + счётчик.
- Несортированные: «Созвоны без папки. Перетащите их в папку слева.» Корзина: «Пусто. Удалённое хранится здесь, пока вы не очистите».

# Мини-тур первого запуска

- Запуск: сразу после последнего шага онбординга («Готово») → «Показать тур (1 мин)» / «Пропустить». Skip доступен на каждом шаге («Пропустить» + Esc), прогресс «2 / 6». Повтор: Настройки → Общие → «Показать тур»; «?» в сайдбаре.
- Реализация: коач-марки поверх настоящего UI (подсветка + карточка рядом), шаги 2–5 показывают миниатюру оверлея, т.к. оверлей скрыт от демонстрации и живёт в отдельном окне.
- Нельзя: блокировать приложение; запускать реальную запись без явного нажатия.

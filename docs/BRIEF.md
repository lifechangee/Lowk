# Lowk — продуктовый бриф (живой документ)

Open-source (AGPL) аналог Cluely с упором на продукт. Платформы: macOS + Windows одновременно. Требование: лёгкое приложение.

## Ядро (нельзя ошибиться)

### 1. Транскрипция в реальном времени (скелет)
- Источники: выбранное приложение или весь звук системы + микрофон. Выбор по умолчанию — в онбординге при первом запуске (с кнопкой «пропустить»).
- Задержка: < 1 с.
- Движки: локально (Whisper Large V3 Turbo — оставить, возможно чанками; Voxtral; другие потоковые модели — ресёрч), облако (OpenRouter вряд ли умеет realtime STT — ресёрч альтернатив).
- Языки: любые, со смешанной речью («А что значит EBITDA?»).
- Говорящие в альфе: только «я» (микрофон) / «система». Диаризация собеседников — роадмап.
- Приложение заранее определяет, потянет ли железо локальную модель, иначе предлагает облако.
- Mac: Apple Silicon, macOS 14+. Windows 10/11.

### 2. Контекст
- Структура: Папка (проект/клиент) → Созвоны → файл созвона (.md). Документы привязаны к папке. Плюс теги.
- Хранение локально в Markdown, просмотр/редактирование/удаление, свой небольшой редактор. Экспорт/импорт. Синхронизация — позже.
- Объём большой: созвоны ежедневно, по несколько часов, несколько в день + документы. Нужен облегчённый «GBrain под нашу задачу».
- Поиск: рассматриваем EmbeddingGemma (вдохновение — github.com/ARahim3/DigUp).
- Документы: PDF, DOCX, TXT/MD. PDF — конвертировать (в предшественнике были проблемы с загрузкой PDF в контекст).

### 3. Ответ нейронки по клавише
- Не автоматически в паузе (как Cluely), а по нажатию.
- Отправляется всё записанное, но как чат: каждый следующий запрос несёт только новое с момента предыдущего.
- Шаблоны промптов; по умолчанию: «кратко ответь на вопрос, заданный в системе/приложении».
- Ответ стримится в оверлее.
- Отдельная клавиша «скриншот» (можно несколько), отдельная «отправить».
- Бинды настраиваемые, включая кнопки мыши (боковые на Windows).
- Модели: облачно через OpenRouter (DeepSeek Flash с/без рассуждений — ресёрч), локально (Gemma 4 — ресёрч).
- MVP — BYOK. Позже — токены/подписка.

## Второстепенное

### 4. Зацикленная камера (последняя по приоритету)
Lowk как виртуальная камера: записать 1/3/5 мин или взять готовое, зациклить. Микрофон не трогаем. При возврате на живую камеру — эффект «пролага»: пикселизация и плавное восстановление качества.

### 5. Стелс
- Оверлей скрыт с демонстрации экрана, из панели задач/Dock/Alt+Tab/трея.
- Процесс не прячем (руткит-техники отклонены). Вместо этого: переименование процесса и смена иконки, в т.ч. «скопировать» внешний вид другого приложения.
- **Критично:** если открыты оба окна (оверлей + главное), оверлей всё равно в стелсе, главное может быть без. В предшественнике это постоянно ломалось.
- Оверлей полупрозрачный и адаптивный: подстраивает фон/обводку/текст под то, что под ним (тёмное/светлое/цветное), плавно, обновление раз в пару секунд.

### 6. Слайды / снимки трансляции (будущее)
Автосохранение смены слайдов на демонстрации + ручной снимок. Двухэтапно: дешёвый локальный дифф кадров → модель Jev (typesafe.ai) решает «новый слайд? да/нет». Порог должен ловить мелкие дописки на слайде (90%+ совпадения ≠ тот же слайд). Изменения вставляются в контекст созвона.

## Окна
- (а) Оверлей на время созвона — всегда стелс.
- (б) Главное окно: библиотека созвонов, редактор md, настройки — стелс не обязателен.

## Прочее
- При первом запуске — предупреждение о законности записи без согласия.
- Подпись кода (Apple Developer / Windows) — пока не делаем, вернёмся при реализации камеры.

## Решения раунда 2 (2026-10-19)

- Оверлей: сверху строка живого транскрипта («субтитры»), ниже ответы нейронки. Фиксированный размер, размер текста в настройках, перетаскивается по всему экрану.
- Мышь: оверлей прозрачен для кликов; по бинду становится интерактивным. Можно печатать нейронке в оверлее (в предшественнике были проблемы с вводом текста — продумать фокус).
- Нейронка отвечает на языке вопроса.
- После созвона по кнопке: краткое саммари.

- Телеметрии нет.
- Дефолты: облачная LLM — DeepSeek V4.1 Flash (OpenRouter), детектор слайдов — Jev.

## Решения по дизайну (итерация 1 макетов, 2026-10-19)
- Оверлей: вариант A (верхняя панель). Без Liquid Glass. Ползунок прозрачности (настройка), без размытия фона.
- Перемещение оверлея: удержание бинда (по умолчанию ⌥/Alt, можно назначить боковую кнопку мыши) — двигаем без входа в интерактивный режим.
- «Мой ответ»: что я сказал в микрофон после подсказки ИИ сохраняется в связке «вопрос → подсказка → мой ответ». Шаблон «Дополни мой ответ» — ИИ добавляет детали к уже сказанному.
- Главное окно: каркас варианта A (три панели), страница созвона — вкладки как в B (Транскрипт / Саммари / Вопросы к AI / Скриншоты).
- Онбординг: утверждён.
- Единый дизайн: монохромный серый («Lowkey»); цветные только функциональные индикаторы (запись, сквозной/интерактивный режим). Рассматривается один приглушённый голубой акцент. Лого — заглушка.
- (итерация 2) Акцент: приглушённый синий. Прозрачность — ползунок для ВСЕГО оверлея (фон, обводка, все элементы), а не только текста; все элементы оверлея (включая выбор шаблона) адаптируются к фону.
- Главное окно: стартовый экран-«главное меню»/библиотека (как B) с явной кнопкой «Новый созвон»; внутри папки/проекта — трёхпанельный режим (как A). Вкладки звонка выровнены.
- (итерация 3, дизайн v3 утверждён с правками, без нового макета):
  - Перемещение: при удержании бинда оверлей «примагничивается» к курсору и следует за ним, без клика и без смены курсора (курсор виден на демонстрации экрана — он не должен выдавать оверлей). Работает в любом режиме; после отпускания режим возвращается прежний.
  - В интерактивном режиме дополнительно можно тянуть оверлей за шапку обычным перетаскиванием (курсор не меняем).
  - Строгие границы текста: статусы (Сквозной/Интерактивный/Перемещение) и любые подписи не вылезают за контейнеры, в т.ч. на английском (длиннее). Проверять на обоих языках.

## Решения раунда 3 (2026-10-20)
- Репозиторий: закрытый GitHub до альфы, затем открыть. Активно используем git (много агентов параллельно → ветки/worktree).
- Язык кода/комментариев/документации: английский; README EN + RU.
- Хранилище по умолчанию: ~/Documents/Lowk (Windows: Документы\Lowk), можно выбрать другую папку/хранилище Obsidian.
- Системные папки: «Несортированные» (созвон без выбранной папки) и «Корзина» (удалённое попадает туда, можно восстановить, как системная корзина).
- Оверлей появляется на основном мониторе.
- Скриншот при нескольких мониторах: снимаются все мониторы (как PrtScr), отправляются в ИИ.
- Бинды по умолчанию: ⌘↵ спросить ИИ, ⌘⇧S скриншот, ⌘⇧A область, ⌘⇧I интерактивный режим, ⌘\ показать/скрыть оверлей, ⌘⇧H паника, удержание ⌥ перемещение, ⌘⇧R запись (Windows: Ctrl вместо ⌘, Alt вместо ⌥). Все меняются в отдельном разделе настроек.
- Два ключа BYOK: OpenRouter (LLM) и облачный STT (Soniox/Deepgram), если выбрана облачная транскрипция.
- Автообновление: проверка GitHub раз в день, выключатель в настройках.
- Windows: тестирование откладываем до доступа к ПК; код под Windows пишем и проверяем компиляцией.
- Оверлей без записи: по умолчанию скрыт (появляется при записи/по бинду); в настройках опция «таблетка» — неприметная полоска на краю экрана, по нажатию стартует запись (тоже скрыта от демонстрации).
- Подпись: пока бесплатная самоподписанная (стабильный сертификат), без Apple Developer.
- Онбординг запрашивает все разрешения для всех функций сразу (экран, микрофон, системный звук, мониторинг ввода и т.д.).
- Боковые кнопки мыши, назначенные в Lowk, перехватываются (браузер не получает «Назад»).
- Иконка в Dock/панели задач — только когда открыто главное окно.
- Корзина хранит вечно + кнопка «Очистить корзину».

## Решения после теста M0 (2026-10-20)
- «Мой ответ» не закрывается автоматически (ни по таймеру, ни по реплике собеседника): это всё, что я сказал после подсказки, до моего следующего нажатия «Спросить ИИ». Управляет только пользователь.
- Транскрипция: приоритет — локальная (дёшево при множестве созвонов, ниже задержка). Сценарий: вопрос задан → я сразу жму бинд → ИИ получает текст без ожидания → ответ стримится, я отвечаю по ходу генерации. Значит: по нажатию бинда в запрос сразу уходит и текущий незавершённый (partial) текст, ничего не ждём. Дефолт — локальный потоковый Nemotron; Whisper/Voxtral — фоновая коррекция для сохранённого транскрипта, никогда не блокирует запрос. Облако — опция.
- Бинд «Паника» убран из дефолтов (действие осталось, назначается вручную). ⌘\ — показать/скрыть оверлей.
- STT (решение архитектора по продуктовым требованиям): live — локальный потоковый Nemotron 3.5 (Mac: MLX; Windows+NVIDIA: ONNX CUDA; слабый CPU: INT8 после теста железа, иначе облако). Фоновая коррекция — Whisper turbo по завершённым фразам (только сохранённый транскрипт/контекст, пропускается при нагрузке). Облако — Soniox по умолчанию, Deepgram запасной (проверить с ключами). Voxtral — отложен до более мощного железа/новых версий.
- Управление оверлеем: отдельные бинды на шаблоны (⌘↵ «Кратко», ⌘⇧↵ «Дополни мой ответ», остальные назначаемы); удержание ⌃ — мышь активна над оверлеем; ⌘⇧I — интерактивный режим только для набора текста; удержание ⌥ — перемещение.
- (замеры 2026-10-21) LLM по умолчанию: `deepseek/deepseek-v4.1-flash-1017` (зафиксированная версия + провайдер), рассуждения выкл.; первое слово ~1,2 с (p95 1,7 с), со скриншотом ~1,4 с; ~$0,05 за 100 запросов. Запасная — `anthropic/claude-haiku-5.5`. Без фиксации версии/провайдера DeepSeek в 2–4 раза медленнее и нестабилен — версию и провайдера всегда пинить.
- Облачный STT по умолчанию: Deepgram Nova-3 multi (WER 0.29, задержка p50 0,6 с / p95 3,3 с, термины латиницей 57–80%). Soniox не проверен — у ключа нулевой баланс (402).
- Языки созвона: пользователь выбирает, на каких языках идёт созвон (по умолчанию в настройках — ru+en / по языку системы; можно поменять перед каждым созвоном). Распознавание и фильтр «чужих» букв ограничиваются выбранными языками. В списке только языки, которые поддерживает движок.

## M2 — решения (2026-10-21)
- Документы в папку: PDF, DOCX, TXT/MD, картинки/скриншоты (OCR), презентации (PPTX/Keynote→PDF) и Excel (XLSX/CSV). Код и прочее — позже.
- Загрузка: перетаскивание в папку в главном окне + кнопка «Добавить документ».
- В нейронку по ⌘↵: инструкции папки (всегда) + релевантные куски документов + релевантные фрагменты прошлых созвонов этой папки.

- Саммари после созвона (по кнопке, делает облачная LLM — DeepSeek): главное 3–5 пунктов, решения, задачи (кто/что), вопросы ко мне и как я ответил.
- Поиск «по смыслу»: локальная EmbeddingGemma (~310 МБ, скачивается вместе с моделями); облако — опция.
- Теги: нейронка предлагает после созвона, пользователь подтверждает; плюс вручную.
- Экспорт/импорт: zip папки или всего хранилища; хранилище открывается в Obsidian.
- Источники под ответом в оверлее (метки документов/созвонов, клик открывает) — да.
- Закреплённые документы папки уходят в нейронку всегда (с лимитом размера) — да.
- Большие файлы: загружаем целиком, в нейронку только релевантные куски; предупреждение о долгой обработке — да.
- UX главного окна: вариант A из docs/design/ux-v4.html (постоянная боковая панель; папка = вкладки Созвоны/Документы/Инструкции) + тур первого запуска (6 шагов, пропускаемый, повтор из настроек и «?»). Реализуем в рамках M2.

# spikes/slides — оффлайн-прототип пре-фильтра смены слайдов

`python3 spikes/slides/prefilter.py --seeds 10` (нужны numpy + Pillow; ~7 с на seed).
Синтетика: новый слайд, +1 буллет, +слово, курсор, тост в углу, «видео»-сегмент, шумный webcam-тайл, шум сжатия.
Jev не вызывается (ключа нет). Результаты: `RESULTS.txt`. Синтетика лёгкая, это не замена реальному корпусу.
